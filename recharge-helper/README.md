# 충전 도우미 (1단계)

고객이 사이트(`/support/recharge`)에 남긴 선불 충전 요청을 가져와서, 프리티 판매점 화면에 **번호를 넣고 가입자 확인까지만** 해 줍니다.
**"freeT 고객 가상계좌 전송" 버튼은 사장님이 직접 누릅니다.** 프로그램은 전송 버튼과 "충 전" 버튼을 절대 누르지 않습니다.

- 사장님 PC 에서만 실행합니다. 이지텍스 프로그램과는 완전히 별개입니다(다른 키, 다른 브라우저 폴더).
- 아직 프리티의 허락을 받기 전이므로 일부러 전송까지 자동으로 하지 않습니다. 허락을 받으면 그때 2단계로 올립니다.
- 시험하지 않은 프로그램입니다. 처음에는 사장님 본인 번호로 접수한 건 한 개로 해 보세요.

## 처음 한 번만

1. Vercel 환경변수와 이 폴더의 `.env` 에 같은 비밀값 `RECHARGE_WORKER_SECRET` 을 넣습니다 (아무도 모르는 긴 영문·숫자, 채팅·커밋에 붙이지 마세요). Vercel 은 넣은 뒤 다시 배포해야 합니다.
2. `.env.example` 을 `.env` 로 복사해 값을 채웁니다.
3. 설치 (이 폴더 안 전용 가상환경 `.venv`에 설치되어 다른 프로그램과 섞이지 않습니다):

```bash
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python -m playwright install chromium
```

(`playwright install` 은 브라우저 파일 약 150MB 를 내려받습니다.)

## 쓰는 법

```bash
.\.venv\Scripts\python helper.py
```

1. 열린 브라우저에서 프리티 판매점에 **직접 로그인**합니다 (처음 한 번. 이후에는 이 폴더의 `profile/` 에 로그인 상태가 남습니다. 비밀번호는 저장되지 않습니다).
2. 요청 한 건마다 번호가 입력되고 "폰번호 정보 확인" 결과(고객정보)가 터미널에 나옵니다.
3. 가입자가 맞으면 화면에서 **"freeT 고객 가상계좌 전송"을 직접 누릅니다**.
4. 터미널에서 `d`(전송했음) / `x`(처리 불가) / `s`(건너뜀) / `q`(그만)를 입력합니다. `d`·`x`는 관리자 화면에 반영되어 목록에서 사라집니다.

## 지켜야 할 것

- 판매점 비밀번호를 이 프로그램이나 `.env` 에 넣지 않습니다.
- 예치금은 0원으로 둡니다 (실수로 "충 전"이 눌려도 돈이 빠지지 않게).
- 프리티가 화면을 바꾸면 번호 입력칸이나 확인 버튼을 못 찾을 수 있습니다. 그때는 화면을 직접 조작하세요.
